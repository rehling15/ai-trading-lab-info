Privacy Policy

AI Trading Lab Backups is a personal integration under development for the owner's private, virtual-only trading research dashboard. This policy describes its intended authorized operation. Google Drive uploads and scheduled backups are not yet enabled.

Google permissions and data

The integration requests the Google Drive drive.file permission to create, read, verify, and manage backup files created through this application. It does not request general access to all Drive files, Gmail, contacts, or calendars.

Information used for backup operation includes authorization tokens and metadata for app-created files, such as file IDs, names, sizes, and creation times. Backup contents consist of the owner's experiment inputs, settings, and saved virtual simulation results. Initial testing uses synthetic data only.

Purpose and sharing

Access is used only for the owner's backup, verification, retention, and restoration operations. Google user data is not sold, used for advertising, or used to train AI models. Backup files are not made public by the application.

The planned services are Google Drive for encrypted backup storage, GitHub Actions for approved backup and restore jobs, and Neon for the test database. Those providers process information under their own terms and privacy policies. This integration is separate from them.

Protection and retention

Backups are encrypted before upload using authenticated AES-256-GCM encryption. The recovery key is kept separately from Google Drive. Once configured, connection credentials and the automation key will be stored as GitHub Actions secrets; the owner should retain a separate recovery copy of the key in a password manager. Trusted automation necessarily has access to plaintext while exporting or restoring; plaintext is not intended for persistent artifact storage or logs.

Retention is limited by available storage and the owner's approved rotation settings. The proposed rotation is seven daily, four weekly, and three monthly recovery points; it is not yet enabled. Only app-created backup files may be removed by a future retention job, after a newer backup has been verified.

Owner control and deletion

The owner can revoke Google access through Google Account settings, disable backup workflows, remove stored integration secrets, and delete app-created files from Drive. Revoking access does not automatically delete existing backup files or database history. Losing the recovery key can make encrypted files unrecoverable.

Contact and policy updates

Use the developer support email displayed on the Google authorization screen for questions or deletion requests. Before any public use or changes in data handling, this policy and the consent configuration must be updated to describe the actual operation.
