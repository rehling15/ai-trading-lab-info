This page generates a random 256-bit key locally in your browser. No key is uploaded, submitted, or stored by this page. It uses no third-party scripts, analytics, or forms.

Generate a key once for this backup setup. Save it in your password manager and as the private GitHub Actions secret BACKUP_RECOVERY_KEY. Never paste it into chat, a repository file, or your Google Drive backup folder.

Losing this key makes encrypted backups unreadable. A newly generated key cannot unlock backups encrypted with an older one. Do not replace a working key without a recovery plan.
